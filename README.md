# Outbreak News

A small website that collects disease outbreak news from public health agencies, uses AI to filter and summarise it, and groups reports about the same outbreak together.

**Sources**
- WHO Disease Outbreak News
- Nigeria Centre for Disease Control (NCDC) press releases
- ECDC, US CDC and PAHO news feeds

**The website has two pages**
- **Latest:** the 20 most recent outbreaks, with older reports on the same outbreak listed under each one.
- **Archive:** every article, with search and filters for disease, country, category and status.

## Quick start: view the website

The database (`outbreaks.db`) is included and already filled in, so the website runs without an internet connection or an API key.

1. Install Python 3.9 or newer from https://www.python.org (on Windows, tick "Add Python to PATH" during setup).
2. Open a terminal in this folder and install the libraries:
   ```
   pip install -r requirements.txt
   ```
3. Start the website:
   ```
   python app.py
   ```
4. Open http://127.0.0.1:5000 in a browser. Press Ctrl+C in the terminal to stop it.

## Updating the data (optional)

`pipeline.py` downloads new articles and processes them. The AI step needs a Google Gemini API key.

1. Get a free key at https://aistudio.google.com/apikey.
2. Set it in the terminal you will run the pipeline from:
   - Windows (PowerShell): `$env:GEMINI_API_KEY = "your-key"`
   - macOS/Linux: `export GEMINI_API_KEY="your-key"`
3. Run:
   ```
   python pipeline.py
   ```

Only articles that are new since the last run are sent to Gemini, so a normal run takes a few minutes. The free Gemini tier allows 500 requests a day, which is enough for daily updates. If the limit is reached, the remaining articles are processed automatically on the next run.

## How it works

`pipeline.py` runs these steps in order:

| Step | File | What it does |
|---|---|---|
| 1 | `collector.py` | Gets WHO Disease Outbreak News from the WHO API. |
| 2 | `scraper_ncdc.py` | Gets the list of NCDC press releases. |
| 3 | `ncdc_fulltext.py` | Downloads the full text of each NCDC press release. |
| 4 | `collector_rss.py` | Gets ECDC, CDC and PAHO news from their RSS feeds. |
| 5 | `database.py` | Saves new articles into `outbreaks.db` (SQLite). |
| 6 | `ai_enrich.py` | Uses Gemini to decide if each article is about an outbreak and to pull out the disease, country, event date, category and status, plus a short summary. |
| 7 | `dedupe.py` | Cleans up disease and country names, then groups reports on the same disease in the same country (published within 60 days of each other) as one outbreak. |

`app.py` is the Flask website. Its HTML is in `templates/` and its CSS is in `static/`.

## Notes on the AI step

- Awareness days, routine vaccination news and organisational announcements are marked "not relevant" and hidden from the website. They stay in the database.
- The event date is only filled in when the article states it. If the article gives only a month, the website shows the month; if it gives no date, the website shows "not stated in report".
- A code check removes event dates that are later than the article's publication date, or whose year doesn't appear in the article.
- Summaries are generated by AI and are labelled as such on the website. Always check the original report, which every card links to.
- To re-run the AI on every article (for example after changing the prompt), set `REPROCESS = True` at the top of `ai_enrich.py`, run it once, then set it back to `False`.
